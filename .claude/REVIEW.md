# Review criteria

Read by the `/review-pr` skill (Scality agent hub) and by anyone reviewing by hand.
Flag problems only — see "What not to flag" at the end.

## What this repo is

`nodeip-discovery` is a Kubernetes node-level agent that discovers the local network
interfaces of the node it runs on, filters their IPv4 addresses against a configured
set of CIDRs and excluded IPs, and writes the result to a Node annotation. It runs as
a DaemonSet so every node advertises the addresses it owns within known networks.

## Criteria

| Area | What to check |
|------|---------------|
| Error wrapping | Wrap errors with `github.com/scality/go-errors` (imported unaliased as `errors`): `errors.Wrap(ErrXxx, ...)` around package-level `ErrXxx` sentinels so `errors.Is` keeps matching; don't swallow errors or ignore returned `err` values |
| Context propagation | Pass `context.Context` through call chains as the first argument; respect cancellation and deadlines; don't store contexts in structs |
| Logging | Standard-library `log/slog`; use the `*Context` methods (`InfoContext`, `ErrorContext`, …) wherever a `context.Context` is in scope |
| Goroutine leaks | Every goroutine must have a clear exit condition; prefer `errgroup`/`sync.WaitGroup`; avoid leaking goroutines on error paths |
| Node / interface discovery logic | Correct enumeration of network interfaces and addresses; robust handling of missing/down interfaces; idempotent Node annotation updates; no clobbering of unrelated annotations |
| Kubernetes / reconciler patterns | Reconciler idempotency, RBAC scoping (least privilege for Node get/patch), annotation updates via strategic-merge patch not full update, proper requeue on transient errors |
| Hexagonal layering | Respect the inward-only dependency rule (`cmd → infrastructure → usecase → service → domain`); entities in `domain`, new ports in `service`, OS/Kubernetes code as adapters in `infrastructure`, application logic in a use case never an adapter |
| Interface compliance | Assert implementations satisfy interfaces at compile time (`var _ Iface = (*Impl)(nil)`) |
| Concurrency safety | Guard shared state with mutexes or channels; check for data races on maps and shared counters |
| Resource cleanup | `defer` close/unlock for files, connections, watchers, and locks; no leaked file descriptors or sockets |
| Config & versioning | Build-time vars (e.g. `ApplicationVersion` via `-ldflags`) stay consistent; env var naming and defaults are backward compatible |
| Dependencies | `go.mod`/`go.sum` changes are tidy and consistent; pin module versions, no unintended major bumps |
| Mocks | Mocks for `service` ports are generated by mockery (`go generate ./...`) and committed; they must not be edited by hand and must not be stale |
| Security | No hardcoded credentials or secrets; validate external input; least-privilege Kubernetes RBAC; keep the distroless/non-root container posture |
| Docs in sync | Behavior/flags/output changes update the README; architecture/design changes update DESIGN.md; convention/workflow changes update CONTRIBUTING.md |
| Breaking changes | Anything that changes public Go APIs, exported types, CLI flags, annotation keys, or container interfaces |

## What not to flag

- Anything the linters already own: `golangci-lint`, `gofmt` — formatting, import
  order, unused variables, naming.
- Markdown or comment wording preferences.
- Refactors unrelated to the PR's purpose.
